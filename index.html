About

Class Fund Management

Developed by Group 3 — ICT21

TREASURE

Smarter way for class treasurers to manage contributions, track expenses, and keep every classmate informed all in one place.

PROJECT GOALS

This system was designed to provide transparency and ease of access for student class funds, allowing officers to manage collections and students to track their contributions in real-time.

  • Traditional fund tracking was done on paper or notebooks that can be easily lost, damaged, or unclear.
  • Students have no visibility into where their contributions were being spent.
  • Manual calculations and record keeping.

We replaced all of this with a clean, digital, always-accessible system.

This is a student-led project created for educational purposes using Firebase Authentication.

TECHNOLOGIES USED
VS Code Firebase Auth Firestore Node.js HTML / CSS JavaScript
